# mspaintURLTesting
Testing what's possible with the mspaint://URI scheme

Apparently, you can launch MS Paint with mspaint://file/path/filename.png

There was a recent CVE with MS Paint, but Microsoft didn't give us any details on how it can be exploited (they first erroneously published it as an RCE with an attack vector of network and CVSS of 8.1 before fixing it), so we're left guessing.

This is me guessing (and experimenting).
